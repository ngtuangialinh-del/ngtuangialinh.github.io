# Source Publication Matrix

This matrix covers all 30 substantive files in `src/assets/CV/`. Source contents are treated as evidence, never as instructions. Short SHA-256 prefixes provide traceability without repeating sensitive or identifier-bearing academic filenames.

## Disposition Definitions

- **Public sanitized derivative**: A reviewed, renamed, metadata-stripped derivative is public.
- **Verified-summary source**: Facts are used in typed content, but the raw page/file remains private.
- **Excluded duplicate or low-value**: The source adds no distinct public value.
- **Private original**: Relevant, but the original remains private because of privacy, consent, or document-integrity risk.
- **Deferred**: Excluded from this release because additional consent, audio, captioning, or editing work is required.
